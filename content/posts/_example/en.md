The text of the post, in GitHub-flavoured Markdown. The title comes from `post.yaml`, so start with the text,
and use `##` for sections: each gets a link to share it.

## Formatting

**Bold**, *italic*, ~~struck~~, [links](/projects) (outside ones open in a new tab), and `inline code`.

```php
echo 'Code blocks keep their formatting';
```

> Quotes, lists, tables and task lists work too.

| Column | Other |
| ------ | ----- |
| a      | b     |

- [x] Done
- [ ] To do
